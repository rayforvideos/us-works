# ADR-0009: Specify Shared UI Components by Variant Tables in Issues Instead of Spec Documents

## Status

Accepted

## Context

ADR-0008은 `feat` 이슈에 스펙 문서를 요구한다. 스펙 템플릿은 화면 단위로 설계되어 API, 화면 상태, 흐름을 절로 가진다. `shared/ui` 컴포넌트에는 API도 화면 상태도 없고, 사양은 Figma 변형 표(속성 × 값 → 배경, 글자, 테두리, 치수)가 전부다. 그 표는 코드의 `cva()` 정의와 1:1로 대응하므로 문서로 한 번 더 쓰면 같은 표를 두 곳에 유지하게 된다.

## Decision

- `shared/ui` 컴포넌트 이슈는 스펙 문서를 쓰지 않는다. ADR-0008의 스펙 요구는 화면 단위 기능에 적용한다.
- 컴포넌트 이슈 본문에 변형 표와 작업 목록을 둔다. 변형 표는 Figma에서 읽은 값으로 채우고, 표에 없는 값은 만들지 않는다.
- 합병 후 기록은 `cva()` 정의와 테스트다. 테스트 이름은 변형 하나를 문장으로 적어 표를 대신한다.

## Consequences

**좋은 점**

- 같은 변형 표를 문서와 코드 두 곳에 유지하지 않는다.

**나쁜 점과 감수하는 위험**

- 변형 표가 이슈에만 남아 저장소만으로는 원래 요구를 볼 수 없다. 테스트 이름이 변형을 문장으로 남기는 것으로 대신한다.
