# 33 알람 목록

## API

- `GET /api/v1/notifications`: 내 알림을 페이지 단위로 가져온다. 쿼리 `page`(기본 1), `limit`(10). 응답은 `notifications`, `total`, `page`, `limit`.

## 범위 밖

- 알림 필터(API에는 있지만 Figma 알람탭에 UI가 없다)
- 알람 작성·수정 페이지(행 클릭은 경로 이동만 한다)

## 데이터와 제약

| 필드      | API 필드                 | 제약                                             | 문구                                    |
| --------- | ------------------------ | ------------------------------------------------ | --------------------------------------- |
| 번호      | `id`                     | 정수                                             | 그대로                                  |
| 제목      | `title`                  | 최대 50자, 한 줄 말줄임                          | 그대로                                  |
| 발송 성공 | `stats.success_count`    | 발송 후에만 있음                                 | 숫자, 없으면 "-"                        |
| 발송 실패 | `stats.failure_count`    | 발송 후에만 있음                                 | 숫자, 없으면 "-"                        |
| 발송 날짜 | `scheduled_at`           | ISO 8601. 예약이면 예정 시각, 발송이면 발송 시각 | `yyyy.MM.dd` 줄바꿈 `HH:mm`, 없으면 "-" |
| 상태      | `send_status`            | pending, sent, failed                            | 예약, 발송, 실패                        |
| 페이지    | `page`, `total`, `limit` | 페이지 수는 `ceil(total / limit)`, 최소 1        | -                                       |

## 화면 상태

- 로딩: 제목과 헤더 행은 그대로 두고 표 영역에 스피너를 보인다.
- 빈 목록: "알림이 없습니다." 페이지네이션은 그리지 않는다.
- 오류: 오류 문구와 "다시 시도" 버튼.
- 성공: 행마다 번호, 제목, 발송 성공, 발송 실패, 발송 날짜, 상태 배지. 아래에 페이지네이션.
- 가능한 행위: 탭 이동, 로고 클릭(콘텐츠 목록 첫 화면 맨 위로), 페이지 이동, 행 클릭, 새 글쓰기.
- 헤더는 화면 위에 고정되어 아래로 스크롤해도 로고·탭·새 글쓰기를 누를 수 있다.
- 페이지는 URL 검색 파라미터(`?page=`)에 있어 새로고침과 뒤로 가기에서 유지된다(ADR-0013).

## 규칙

- R-01 발송 상태 `sent`는 "발송"과 green, `pending`은 "예약"과 yellow, `failed`는 "실패"와 red 배지다
- R-02 발송 날짜는 `yyyy.MM.dd`와 `HH:mm` 두 줄로 표시하고, 값이 없으면 "-"다
- R-03 발송 성공·실패 수는 `stats`가 없으면 "-"다
- R-04 URL의 `page`가 1 미만이거나 숫자가 아니면 1로, 9999를 넘으면 9999로 읽는다

## 흐름

- S-01 Given 목록을 불러오는 중 When 페이지가 렌더링되면 Then 표 영역에 로딩 표시가 보인다
- S-02 Given 목록 응답이 있을 때 When 렌더링되면 Then 행마다 번호, 제목, 발송 성공, 발송 실패, 발송 날짜, 상태 배지가 보인다
- S-03 Given 목록이 비어 있을 때 When 렌더링되면 Then "알림이 없습니다."가 보인다
- S-04 Given 목록 요청이 실패했을 때 When 렌더링되면 Then 오류 문구와 "다시 시도" 버튼이 보이고 버튼을 누르면 다시 요청한다
- S-05 Given 1페이지를 보고 있을 때 When 2페이지를 누르면 Then URL이 `?page=2`가 되고 2페이지를 요청한다
- S-06 Given 목록 행이 있을 때 When 행을 클릭하면 Then `/alarms/<id>`로 이동한다
- S-07 Given 알람 탭 When "콘텐츠" 탭을 누르면 Then `/`로 이동한다
- S-08 Given `/alarms`에 있을 때 When 헤더를 보면 Then "알람" 탭이 선택 상태다
- S-09 Given 알람 탭 When 로고를 누르면 Then `/`로 이동하고 창 스크롤이 맨 위로 이동한다
