# 22 GNB

## API

- 없음. GNB는 API를 호출하지 않는다.

## 범위 밖

- 목록 페이지 상단의 로고·탭 헤더(GNB가 아니며 목록 페이지 작업 때 다룬다)
- 임시저장, 발행 동작 자체(GNB는 페이지가 넘긴 버튼을 우측에 놓기만 한다)
- 뒤로가기의 실제 이동(페이지가 `onBack`으로 정한다)

## 데이터와 제약

| 필드      | API 필드 | 제약                                                                           | 문구                    |
| --------- | -------- | ------------------------------------------------------------------------------ | ----------------------- |
| 제목      | -        | 페이지가 넘기는 문자열. 없으면 그리지 않는다                                   | 페이지가 정한다         |
| 상태 문구 | -        | 페이지가 넘기는 문자열. 없으면 그리지 않는다                                   | 페이지가 정한다         |
| 뒤로가기  | -        | 페이지가 `onBack`을 넘기면 보이고, 넘기지 않으면 없다                          | 접근성 이름 "뒤로 가기" |
| 우측 버튼 | -        | 페이지가 넘기는 요소. 저장 중 표시는 페이지가 버튼을 로딩 상태로 두어 표현한다 | -                       |

## 화면 상태

- 로딩, 빈 목록, 오류 상태가 없다. 페이지가 넘긴 뒤로가기, 제목, 상태 문구, 우측 버튼이 그대로 보인다.
- 저장 중에는 임시저장 버튼이 크기와 색을 유지한 채 라벨 자리에 스피너를 보인다.
- 가능한 행위는 뒤로가기 클릭과 우측 버튼 클릭이다.
- GNB는 페이지 상단의 banner 랜드마크다.

## 규칙

- 없음.

## 흐름

- S-01 Given 제목을 넘겼을 때 When GNB가 렌더링되면 Then 제목이 1단계 헤딩으로 보인다
- S-02 Given 상태 문구를 넘겼을 때 When GNB가 렌더링되면 Then 그 문구가 보인다
- S-03 Given 상태 문구를 넘기지 않았을 때 When GNB가 렌더링되면 Then 상태 문구 영역이 없다
- S-04 Given `onBack`을 넘겼을 때 When 뒤로가기를 클릭하면 Then `onBack`이 한 번 호출된다
- S-05 Given `onBack`을 넘기지 않았을 때 When GNB가 렌더링되면 Then 뒤로가기 버튼이 없다
- S-06 Given 우측 버튼 요소를 넘겼을 때 When GNB가 렌더링되면 Then 그 요소가 우측에 보인다
- S-07 Given GNB가 렌더링된 상태 When 접근성 트리를 보면 Then banner 랜드마크가 있다
