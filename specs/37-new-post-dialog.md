# 37 새글쓰기 모달

## API

- 없음. 로컬 스토리지의 임시저장(`us-works.content-draft`)을 읽고 지운다.

## 범위 밖

- 콘텐츠 작성 페이지 자체(#35에서 완료)
- 발행 옵션 모달과 확인 다이얼로그(공용 다이얼로그 껍데기만 이번에 만든다)

## 데이터와 제약

| 필드      | API 필드           | 제약                                         | 문구                                                 |
| --------- | ------------------ | -------------------------------------------- | ---------------------------------------------------- |
| 임시저장  | 로컬 스토리지      | 있으면 이어쓰기 항목을 보이고, 없으면 숨긴다 | "임시 저장된 콘텐츠 이어서 쓰기"                     |
| 저장 시각 | 임시저장 `savedAt` | ISO 8601 → Asia/Seoul                        | "(임시 저장된 시간 : YYYY년 MM월 DD일 HH:mm)"        |
| 새 글     | -                  | 항상 보인다                                  | "콘텐츠 쓰기", "커뮤니티, 소통이 가능한 기본 포스트" |

## 화면 상태

- 닫힘: 목록 헤더 우측에 "새 글쓰기" 버튼만 보인다.
- 열림: 배경이 어두워지고 가운데 "새글쓰기" 제목, 닫기 버튼, 선택지 목록이 보인다. 항목에 마우스를 올리거나 포커스하면 아이콘 원 배경(blue-green-20)이 보인다. 포커스는 다이얼로그 안에 머물고 Esc, 닫기, 배경 클릭으로 닫힌다.
- 임시저장 있음: 이어쓰기 항목(저장 시각 포함)과 콘텐츠 쓰기 항목 둘. 없음: 콘텐츠 쓰기 항목 하나.
- 선택 뒤: 다이얼로그가 닫히고 `/contents/new`로 이동한다.

## 규칙

- R-01 저장 시각은 Asia/Seoul 기준 "YYYY년 MM월 DD일 HH:mm"으로 표시한다
- R-02 임시저장이 없으면 이어쓰기 항목을 만들지 않는다

## 흐름

- S-01 Given 목록 페이지 When "새 글쓰기"를 누르면 Then "새글쓰기" 다이얼로그가 열린다
- S-02 Given 임시저장이 없을 때 When 다이얼로그가 열리면 Then "콘텐츠 쓰기" 항목만 보인다
- S-03 Given 임시저장이 있을 때 When 다이얼로그가 열리면 Then 이어쓰기 항목에 저장 시각이 보이고 콘텐츠 쓰기 항목도 보인다
- S-04 Given 임시저장이 있을 때 When 이어쓰기를 누르면 Then 임시저장을 유지한 채 `/contents/new`로 이동한다
- S-05 Given 임시저장이 있을 때 When 콘텐츠 쓰기를 누르면 Then 임시저장을 지우고 `/contents/new`로 이동한다
- S-06 Given 다이얼로그가 열린 상태 When Esc를 누르거나 닫기 버튼을 누르면 Then 다이얼로그가 닫히고 포커스가 "새 글쓰기" 버튼으로 돌아간다
- S-07 Given 알람 탭 When "새 글쓰기"를 누르면 Then 같은 다이얼로그가 열린다
- S-08 Given 모달을 닫은 뒤 임시저장이 생겼을 때 When 모달을 다시 열면 Then 이어쓰기 항목이 보인다
