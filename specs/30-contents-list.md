# 30 콘텐츠 목록

## API

- `GET /api/v1/contents`: 내 콘텐츠를 페이지 단위로 가져온다. 쿼리 `page`(기본 1), `limit`(10), `category`, `publish_status`. 응답은 `contents`, `total`, `page`, `limit`.

## 범위 밖

- 새 글쓰기 버튼과 모달(다음 기능), 콘텐츠 작성·수정 페이지(행 클릭은 경로 이동만 한다)
- 푸터(만들지 않는다)
- 알람 탭 목록(같은 헤더를 쓰지만 별도 이슈)
- 알람 작성 페이지(푸시알림 생성 링크는 경로 이동만 한다)
- 통계(조회·좋아요·댓글 수) 표시

## 데이터와 제약

| 필드          | API 필드                               | 제약                                      | 문구                                  |
| ------------- | -------------------------------------- | ----------------------------------------- | ------------------------------------- |
| 번호          | `id`                                   | 정수                                      | 그대로                                |
| 제목          | `title`                                | 최대 50자, 한 줄 말줄임                   | 그대로                                |
| 공개일자      | `published_at`                         | ISO 8601. 없으면 빈 값                    | `yy.MM.dd` 줄바꿈 `HH:mm`, 없으면 "-" |
| 상태          | `publish_status`                       | draft, scheduled, published               | 비공개, 예약, 공개                    |
| 카테고리 필터 | `category`                             | enum 11개 또는 없음                       | 한글 라벨, 없으면 "카테고리"          |
| 상태 필터     | `publish_status`                       | enum 3개 또는 없음                        | 한글 라벨, 없으면 "상태"              |
| 페이지        | `page`, `total`, `limit`               | 페이지 수는 `ceil(total / limit)`, 최소 1 | -                                     |
| 푸시알림      | `notification_status.has_notification` | 알림이 없는 콘텐츠에만 생성 링크          | "푸시알림 생성"                       |

## 화면 상태

- 로딩: 제목·필터·헤더 행은 그대로 두고 표 영역에 스피너를 보인다.
- 빈 목록: "콘텐츠가 없습니다." 문구. 필터가 걸려 있으면 "조건에 맞는 콘텐츠가 없습니다."
- 오류: 오류 문구와 "다시 시도" 버튼.
- 성공: 행마다 번호, 제목, 공개일자, 상태 배지. 행에 마우스를 올리거나 포커스하면 배경이 옅어지고 제목 오른쪽에 "푸시알림 생성" 링크(버튼 모양)가 보인다(알림이 없는 콘텐츠만). 아래에 이전·다음과 최대 5개 번호의 페이지네이션.
- 가능한 행위: 탭 이동, 로고 클릭(맨 위로), 필터 변경, 페이지 이동, 행 클릭, 푸시알림 생성. 새 글쓰기 버튼은 다음 기능(새글쓰기 모달)에서 헤더의 액션 자리에 넣는다.
- 필터와 페이지는 URL 검색 파라미터(`?page=&category=&publish_status=`)에 있어 새로고침과 뒤로 가기에서 유지된다.

## 규칙

- R-01 카테고리 값은 정해진 한글 라벨로 바꾸고, 목록에 없는 값이면 값 그대로 보인다
- R-02 발행 상태 `published`는 "공개"와 green, `scheduled`는 "예약"과 yellow, `draft`는 "비공개"와 grey 배지다
- R-03 공개일자는 `yy.MM.dd`와 `HH:mm` 두 줄로 표시하고, 값이 없으면 "-"다
- R-04 페이지 수는 `total`을 `limit`으로 나눠 올림한 값이며 최소 1이다
- R-05 URL의 `page`가 1 미만이거나 숫자가 아니면 1로, `category`·`publish_status`가 enum에 없으면 없는 것으로 읽는다
- R-06 페이지네이션은 현재 페이지를 가운데 둔 최대 5개 번호를 보이고, 첫 페이지에서 이전, 마지막 페이지에서 다음이 비활성이다

## 흐름

- S-01 Given 목록을 불러오는 중 When 페이지가 렌더링되면 Then 표 영역에 로딩 표시가 보인다
- S-02 Given 목록 응답이 있을 때 When 렌더링되면 Then 행마다 번호, 제목, 공개일자, 상태 배지가 보인다
- S-03 Given 목록이 비어 있을 때 When 렌더링되면 Then "콘텐츠가 없습니다."가 보인다
- S-04 Given 목록 요청이 실패했을 때 When 렌더링되면 Then 오류 문구와 "다시 시도" 버튼이 보이고 버튼을 누르면 다시 요청한다
- S-05 Given 2페이지를 보고 있을 때 When 상태 필터를 "공개"로 바꾸면 Then URL이 `?publish_status=published`가 되고 1페이지를 요청한다
- S-06 Given 1페이지를 보고 있을 때 When 2페이지를 누르면 Then URL이 `?page=2`가 되고 2페이지를 요청한다
- S-07 Given 목록 행이 있을 때 When 행을 클릭하면 Then `/contents/<id>`로 이동한다
- S-08 Given 알림이 없는 콘텐츠 행 When 행에 포커스하고 "푸시알림 생성"을 누르면 Then `/alarms/new?contentId=<id>`로 이동하고 행 클릭 이동은 일어나지 않는다
- S-09 Given 알림이 있는 콘텐츠 행 When 행에 포커스하면 Then "푸시알림 생성" 버튼이 없다
- S-10 Given 콘텐츠 탭 When "알람" 탭을 누르면 Then `/alarms`로 이동한다
- S-11 Given 아래로 스크롤된 상태 When 로고를 누르면 Then 창 스크롤이 맨 위로 이동한다
